# profile-app (GoAgent demo fixture)

Small React + Express + SQLite app with in-house JWT auth and a read-only profile page.
GoAgent's canonical demo asks agents to add **authenticated profile editing**.

- `pnpm test` runs Vitest (server API + web API client)
- `pnpm dev:server` / `pnpm dev:web`
- Demo login: `demo@example.com` / `demo-password`
